# Cyclistic Bike-Share Data Analysis

## Business Problem
Cyclistic wants to understand how annual members and casual riders use bikes differently in order to improve membership conversion strategies.

---

## Tools Used
- Python
- pandas
- Matplotlib
- Jupyter Notebook

---

## Data Cleaning Process
- Combined 12 monthly CSV files
- Removed duplicate rows
- Converted date columns into datetime format
- Created ride_length column
- Removed invalid ride durations and outliers

---

## Analysis
The analysis revealed that annual members and casual riders use Cyclistic bikes differently.

Key findings:
- Casual riders take longer rides on average
- Members ride more consistently during weekdays
- Casual riders are more active on weekends

## Recommendations

3. Develop seasonal recreational marketing campaigns

---

## Final Conclusion
The analysis identified clear behavioral differences between annual members and casual riders. These insights can help Cyclistic create targeted marketing strategies designed to increase membership conversions.
